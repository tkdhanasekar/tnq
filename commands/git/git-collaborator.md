If you're the **repository owner** or have **admin access**, you can add someone as a collaborator (contributor) to a GitHub repository:

1. Open the repository on GitHub.
2. Click **Settings**.
3. In the left sidebar, click **Collaborators** (or **Collaborators and teams** if it's under an organization).
4. Click **Add people** or **Add collaborator**.
5. Search for the user's GitHub username.
6. Select the user and click **Add** (or **Invite**).
7. The user will receive an invitation. They must **accept the invitation** before they can contribute.

### Choosing permissions

When inviting the user, you can assign an appropriate role, such as:

* **Read** – Can view the repository.
* **Triage** – Can manage issues and pull requests.
* **Write** – Can push code and create branches.
* **Maintain** – Can manage the repository without full admin rights.
* **Admin** – Full control over the repository.

### If the repository belongs to an organization

Instead of adding an individual collaborator, it's often better to:

1. Go to the organization's **Teams**.
2. Add the user to a team.
3. Grant the team the appropriate access to the repository.

### If you don't see "Settings" or "Add collaborator"

You likely don't have **admin** permissions on the repository. In that case, ask the repository owner or an administrator to invite the user.
